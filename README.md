# SoundTray
A simple sound application to switch audio devices (input and output) from the application's system tray icon.

Customizable in the sense you can disable both input and output items so they don't appear in the context menu when you right click the menu from the system tray.

Stores it's settings in pipe delimited values in a cfg file in the application folder.

Please note that you cannot disable an input or output device that is currently set as the default.  To disable the default device you need to switch the default device to a different device first, then try.
